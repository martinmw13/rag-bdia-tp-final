\section{Implementación mínima realizada}

La prueba funcional se ejecuta en fases numeradas. El esquema crea extensiones,
tablas y restricciones. El seed carga los datos sintéticos. Los scripts
siguientes agregan índices, la vista de recuperación, roles, privilegios, RLS y
auditoría. Otros archivos ejecutan los casos C1--C9 y las validaciones negativas
de integridad y seguridad.

\path{scripts/cargar_base.sh} regenera los artefactos, recrea la base y muestra
los casos. \path{scripts/validar_base.sh} hace la validación completa. Sólo
acepta una base terminada en \texttt{\_validacion}; la recrea dos veces,
comprueba conteos y checksums, prueba el rechazo de operaciones inválidas,
valida permisos y compara instantáneas ordenadas.

La implementación termina en la capa de datos. No se agrega un backend ni una
interfaz para simular una aplicación completa. Las pruebas usan SQL y roles
técnicos para comprobar cada contrato de forma directa.
