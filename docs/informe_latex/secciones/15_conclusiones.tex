\section{Conclusiones}

Se implementó una capa de datos pequeña para un copiloto RAG interno. PostgreSQL
guarda datos operativos, documentos versionados, embeddings, permisos,
interacciones y auditoría. La vigencia y la autorización reducen el universo
antes del ranking, y cada respuesta conserva la evidencia que la sostuvo.

La prueba funcional valida claves, restricciones, invariantes diferidas,
publicación atómica, RLS, privilegios mínimos y auditoría append-only mediante
nueve casos. La semilla 42 produce los mismos archivos, conteos y checksums; la
validación recrea la base dos veces y compara sus instantáneas. Para 36
embeddings, una exploración secuencial (\texttt{Seq Scan}) cuesta menos que usar
HNSW. El índice queda disponible para un corpus mayor.

No se implementan autenticación, API, LLM, embeddings reales ni infraestructura
distribuida, y la muestra no se usa como benchmark. Antes de escalar se deben
medir el crecimiento y los cuellos reales. Según el resultado, se podrá
particionar la auditoría, agregar réplicas, mover archivos o evaluar un motor
vectorial separado. Cualquier cambio deberá mantener la autorización antes del
ranking y la trazabilidad histórica.
