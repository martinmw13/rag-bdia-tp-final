\subsection{Modelo lógico relacional}

tablas, columnas, claves y relaciones entre tres figuras para que puedan leerse
sin perder la correspondencia con el esquema. Las
Figuras~\ref{fig:logico-operacion} a~\ref{fig:logico-interaccion} deben leerse
en conjunto.

Las entidades con identidad propia usan claves sustitutas. Los códigos de
producto, cliente, proveedor, pedido y documento funcionan como claves de
negocio únicas. Las tablas asociativas usan claves compuestas cuando la pareja
de referencias identifica la fila. El recorrido documental enlaza
\texttt{documento}, \texttt{version\_documental}, \texttt{fragmento} y
\texttt{embedding}; la evidencia conserva la referencia exacta que permite
reconstruir la fuente de una respuesta.

Los índices B-tree acompañan claves foráneas, filtros y joins usados por las
consultas representativas. El índice HNSW cubre el acceso vectorial. Los
intervalos semiabiertos y las restricciones \texttt{EXCLUDE USING gist}

constraint triggers diferidos comprueban al cierre de la transacción las
reglas que no pueden expresarse sobre una sola fila.
